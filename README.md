# Personal Blog Portfolio

## Description
This project is a personal blog portfolio website developed for the CSD34203 Special Topics in Software Development course. The website presents my personal background, skills, blog posts, and contact information through a clean, responsive, and user-friendly interface.

## Features
- Home page with personal introduction
- About page with personal details and skills
- Blog page with sample blog posts
- Contact page with form layout
- Dark mode toggle feature
- Fully responsive design for mobile and desktop
- Smooth navigation between pages

## Technologies Used
- HTML5
- CSS3
- JavaScript
